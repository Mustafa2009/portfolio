# Dr. Mustafa Ghaleb — Academic Portfolio

A modern, responsive academic portfolio website built with React, Tailwind CSS, and Framer Motion.

**Live site:** [https://mustafa2009.github.io/portfolio/](https://mustafa2009.github.io/portfolio/)

## About

Dr. Mustafa Mohammed Saeed Ghaleb is an Assistant Professor in the Department of Software Engineering at Kocaeli University, Turkiye. His research interests include computer networks, cybersecurity, IoT, distributed computing, NLP, trust modeling, and deep learning applications.

## Tech Stack

- **React 18** — UI framework
- **Vite 5** — Build tool
- **Tailwind CSS 3** — Utility-first styling
- **Framer Motion** — Animations
- **React Icons** — Icon library
- **GitHub Pages** — Hosting via GitHub Actions

## Sections

| Section | Description |
|---------|-------------|
| Hero | Animated intro with name, title, and research tags |
| About | Biography, real profile photo, and academic metrics |
| Skills | Technical skills grouped by category with progress bars |
| Research | Funded research projects with roles (PI/Co-PI/Researcher) |
| Journey | Academic experience and education timeline |
| Awards | Best Paper, medals, and patent highlights |
| Publications | 8 recent publications from AVESIS/Google Scholar |
| Contact | Contact form, email, phone, and academic profile links |

## Quick Start

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## Deployment

Pushes to `main` automatically deploy via GitHub Actions (`.github/workflows/deploy.yml`).
